# Licensing notes

This project has not yet published a formal LICENSE file; this document records the intended licensing approach
(Master Development Specification §19) until the project owner formally adopts one.

## Original project content

- **Software** (`engine/`, `website/`, `tests/`, build/config files): intended to be released under a permissive
  open-source license (e.g. MIT) once formally adopted, so the engine and site can be reused and extended.
- **Original linguistic data** (`data/*.json`: the Gurzûl Khar phonology, orthography, grammar, and lexicon): the
  project owner's original creative work. Intended to be shared under a Creative Commons license that requires
  attribution (e.g. CC BY 4.0) so others may study, teach, or build on the language while crediting the project.
- **Artwork** (the procedurally generated Khargûl glyphs, the logo): original work, intended to be covered by the
  same attribution-required license as the linguistic data.
- **Educational explanations and example texts** (grammar reference prose, lesson content, lore): original writing,
  same attribution-required license as the linguistic data.

## Third-party / referenced material

GURZÛL KHAR is inspired by the linguistic atmosphere of J.R.R. Tolkien's Black Speech but reproduces none of
Tolkien's actual Black Speech vocabulary, grammar, or writing systems (see `DESIGN_DECISIONS.md` §D4). No
copyrighted Tolkien text is included in this repository. References to Tolkien's work in this project's
documentation are commentary/inspiration citations, not reproductions.

## What this means in practice right now

Until a LICENSE file is added to the repository root, the default is **all rights reserved** by the project owner
for any content not otherwise marked. This document states the *intended* direction, not a substitute for a real
license file — anyone wanting to reuse this project's content should contact the project owner, or wait for a
formal LICENSE to be published.
